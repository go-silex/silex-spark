# Contribuer

Ce dépôt est un **miroir en lecture seule** généré depuis `go-silex/spark` (`plugins/silex-spark/`).

Les PRs et Issues ouvertes ici ne sont pas suivies et sont **écrasées** à la prochaine synchro.

**Pourquoi.** Le plugin est le **client de l’API Spark** : un changement d’endpoint et son exposition CLI doivent atterrir dans le **même commit** (mesuré : ~80 % des commits plugin touchent aussi `src/`).

## Signaler un bug ou demander une évolution

| Besoin | Canal |
|--------|--------|
| Bug, régression, demande d’évolution | Bouton **Signaler** dans Spark |
| Autre | Contact Silex |

Ne pas ouvrir d’Issue ni de PR sur ce dépôt.
